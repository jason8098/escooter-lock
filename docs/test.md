# SSR Checks

- With only USB 5 V connected, measure 5 V across board `IN+`/`IN-`.
- After Unlock, measure the SSR input active and verify it remains active after
  Bluetooth disconnect.
- After Web Lock, reset, or USB removal, verify the SSR input is inactive.
- With the scooter wheel raised, verify opening yellow has the required lock
  effect before riding.
